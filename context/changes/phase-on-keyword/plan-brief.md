# Phase Relevance on Keyword — Plan Brief

> Full plan: `context/changes/phase-on-keyword/plan.md`

## What & Why

FR-007 requires players to see when a keyword matters — e.g. *Close Quarters* only in Engagement — including when it **does not** apply outside that phase. A single optional line exists today; S-03 adds structured applicability and a prominent phase banner.

## Phases

1. Corpus + lookup contract — `phaseApplicability: 'restricted' | 'general'` on hits
2. `PhaseRelevance` UI in result card + tests
